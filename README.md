# 🤖 AI Chatbot Backend

Backend API for the AI Chatbot built with Node.js and Express.js. It integrates the Gemini API to generate AI responses and serves the frontend through REST endpoints.

## 🚀 Features

- REST API
- Gemini API Integration
- JSON Request Handling
- CORS Enabled
- Environment Variable Support

## 🛠️ Tech Stack

- Node.js
- Express.js
- Gemini API
- dotenv
- cors
